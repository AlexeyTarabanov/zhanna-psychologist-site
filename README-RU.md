# Сайт психолога Жанны Тарабановой

Исходники одностраничного сайта-визитки на React, TypeScript и Vinext.

## Требования

- Node.js 22.13 или новее
- npm

## Локальный запуск

```bash
nvm use
npm ci
npm run dev
```

После запуска адрес будет показан в терминале.

## Проверка production-сборки

```bash
npm ci
npm run build
npm run start
```

## Основные файлы

- `app/page.tsx` — содержимое страницы.
- `app/globals.css` — дизайн и адаптивная вёрстка.
- `app/layout.tsx` — заголовок и описание сайта.
- `public/zhanna.jpg` — фотография Жанны.

## Перенос на сервер

1. Установите Node.js 22 и распакуйте архив.
2. Выполните `npm ci`.
3. Соберите проект командой `npm run build`.
4. Запустите командой `npm run start`.
5. Настройте Nginx или другой reverse proxy на порт, который покажет приложение.
6. Подключите домен и HTTPS у своего хостинг-провайдера.

Служебная привязка к ChatGPT Sites в архив не включена. Код, стили и фотография работают независимо от опубликованной версии.
